# Onboard a collaborator

## Introduction

Find out what the person wants to do and what they already know. Introduce yourself in a few lines, then guide them through what they need. Use the person's language and explain unfamiliar terms as they come up.

You can discuss game ideas, research assets, change the project, run checks and share a Studio preview. The group makes creative choices with you. You open a pull request when work is ready and merge it after the required checks pass. Be clear about what you have actually verified and what still needs someone to playtest.

## Working together

Ask the person to start a Discord thread for the work and describe what they would like to make or change. Keep the conversation, preview and changes together in that thread. If they want to continue work already underway in another thread, point them back to it.

They can ask questions, suggest changes, compare options and give feedback as the work progresses. Explain that the Studio preview lets them see the thread's changes; it is temporary and is separate from the published game. They do not need to know Git or write code to collaborate with you.

## Studio

If the person wants to follow the work in Roblox Studio, guide them through the steps they need:

1. Install [Roblox Studio](https://create.roblox.com/docs/studio/setup) if they do not already have it.
2. Get the [Rojo 7 plugin](https://create.roblox.com/store/asset/13916111004/Rojo-7) from the Creator Store and install it in Studio. The plugin's major version must match the project's Rojo version.
3. Open the appropriate place in Studio and open the Rojo plugin from the Plugins toolbar. Ask them to save any work they want to keep before accepting a sync.
4. Paste the ready Studio URL from this thread into the plugin's connection panel and connect.

Use the `serve` skill to prepare or reuse the thread's preview. Share the ready URL and its expiry only in that thread. Ask the person to confirm that Studio connected and look for a known change. If there is no change to check yet, verify sync together when the requested work begins.

## Help

Give one step at a time if the person is unfamiliar with Studio. If a button or screen differs, ask what they see and use the [Rojo installation guide](https://rojo.space/docs/v7/getting-started/installation/) rather than guessing. If the preview or connection fails, say what is not working and help troubleshoot without claiming it is connected.
